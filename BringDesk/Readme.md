# BringDesk

A simple Bash utility for creating desktop shortcuts for installed applications on Ubuntu.

## Features

- Search applications by launcher filename
- Search applications by their displayed name
- Supports multiple application launcher directories
- Creates shortcuts on the Desktop
- Simple interactive selection

## Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/bringdesk.git
cd bringdesk
```

Run the installer:

```bash
bash install.sh
```

## Usage

```bash
bringdesk
```

Search for an application and select it from the displayed list.

## Requirements

- Ubuntu/Linux
- Bash
- `find`
- `grep`
- `xdg-user-dir`
